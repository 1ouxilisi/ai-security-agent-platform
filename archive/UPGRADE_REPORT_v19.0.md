- 所有模块使用 `from __future__ import annotations`

- 每个端点 try-except 兜底，不抛500
- `_clean()` 递归清理控制字符
- 内存字典 `TASKS` 模拟异步任务
- 深色安全工具主题，UTF-8编码，响应式设计

- 全部为检测/监控/分析/管理/测试视角
