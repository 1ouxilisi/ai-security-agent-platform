# AI Hacking Agent 部署文档

## 一、环境要求

### 基础环境
- **操作系统**：Windows 10/11、Ubuntu 20.04+、CentOS 8+、macOS 10.15+
- **Python**：3.10 或更高版本（推荐 3.10/3.11）
- **内存**：最低 2GB，推荐 4GB+
- **磁盘**：最低 2GB 可用空间
- **网络**：需要能访问外网（用于安装依赖和调用AI API）

### 可选工具
- **Git**：用于克隆项目（可选，直接下载zip也行）
- **Docker**：用于容器化部署（可选）
- **Nmap**：用于端口扫描（可选，不装也能跑，部分功能受限）
- **Nuclei**：用于漏洞模板扫描（可选，不装也能跑，部分功能受限）

## 二、Windows 部署步骤

### 第1步：安装 Python
1. 打开 https://www.python.org/downloads/
2. 下载 Python 3.10 或更高版本
3. 运行安装程序，**勾选 "Add Python to PATH"**（非常重要）
4. 点击 "Install Now" 安装
5. 安装完成后，打开命令提示符（cmd），输入 `python --version`，确认显示版本号

### 第2步：解压项目
1. 把项目压缩包解压到任意目录，比如 `D:\ai-hacking-agent`
2. 进入项目目录，确认能看到 `main.py`、`requirements.txt` 等文件

### 第3步：安装依赖
1. 打开命令提示符（cmd）
2. 进入项目目录：
   ```
   cd D:\ai-hacking-agent
   ```
3. 安装依赖：
   ```
   pip install -r requirements.txt
   ```
4. 等待安装完成（可能需要3-5分钟，取决于网络速度）
5. 如果安装失败，尝试升级pip：
   ```
   python -m pip install --upgrade pip
   ```
   然后重新安装依赖。

### 第4步：配置 API 密钥
1. 在项目根目录创建 `.env` 文件（注意文件名前面有个点）
2. 用记事本打开 `.env` 文件，填入以下内容：
   ```
   # AI API 配置（必填，至少填一个）
   LLM_API_KEY=你的API密钥
   LLM_BASE_URL=https://api.deepseek.com/v1
   LLM_MODEL=deepseek-chat

   # 或者用 OpenAI 兼容的其他平台
   # LLM_API_KEY=你的API密钥
   # LLM_BASE_URL=https://api.openai.com/v1
   # LLM_MODEL=gpt-3.5-turbo

   # 服务配置（可选，有默认值）
   API_HOST=127.0.0.1
   API_PORT=8000
   DEBUG=false
   ```
3. 保存文件

**API密钥获取方式：**
- DeepSeek：https://platform.deepseek.com/ 注册，创建API密钥
- 硅基流动：https://siliconflow.cn/ 注册，创建API密钥
- OpenAI：https://platform.openai.com/ 注册，创建API密钥
- 任何兼容OpenAI API的平台都可以

### 第5步：初始化数据库
1. 在命令提示符中，进入项目目录：
   ```
   cd D:\ai-hacking-agent
   ```
2. 运行初始化命令：
   ```
   python main.py init
   ```
3. 等待初始化完成，会创建数据库和默认数据

### 第6步：启动 API 服务
1. 在命令提示符中，进入项目目录：
   ```
   cd D:\ai-hacking-agent
   ```
2. 启动服务：
   ```
   python main.py api-server --host 127.0.0.1 --port 8000
   ```
3. 看到 `Uvicorn running on http://127.0.0.1:8000` 表示启动成功
4. 打开浏览器，访问 http://127.0.0.1:8000/docs ，能看到Swagger UI界面

### 第7步：启动 Web UI（可选）
1. 新开一个命令提示符窗口
2. 进入项目目录：
   ```
   cd D:\ai-hacking-agent
   ```
3. 启动Web UI：
   ```
   streamlit run web_ui/app.py
   ```
4. 浏览器会自动打开 http://localhost:8501

## 三、Linux 部署步骤（Ubuntu/Debian）

### 第1步：安装 Python 和依赖
```bash
# 更新包列表
sudo apt update

# 安装 Python 3.10 和 pip
sudo apt install -y python3.10 python3-pip python3-venv

# 验证安装
python3 --version
pip3 --version
```

### 第2步：解压项目
```bash
# 解压项目
unzip ai-hacking-agent.zip -d /opt/
cd /opt/ai-hacking-agent
```

### 第3步：创建虚拟环境（推荐）
```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
source venv/bin/activate
```

### 第4步：安装依赖
```bash
# 升级pip
pip install --upgrade pip

# 安装项目依赖
pip install -r requirements.txt
```

### 第5步：配置 API 密钥
```bash
# 创建.env文件
cat > .env << EOF
LLM_API_KEY=你的API密钥
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
API_HOST=0.0.0.0
API_PORT=8000
DEBUG=false
EOF
```

### 第6步：初始化数据库
```bash
python main.py init
```

### 第7步：启动服务
```bash
# 前台启动（测试用）
python main.py api-server --host 0.0.0.0 --port 8000

# 后台启动（生产用，需要nohup）
nohup python main.py api-server --host 0.0.0.0 --port 8000 > server.log 2>&1 &
```

### 第8步：配置 systemd 服务（可选，生产推荐）
```bash
# 创建服务文件
sudo cat > /etc/systemd/system/ai-hacking-agent.service << EOF
[Unit]
Description=AI Hacking Agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/ai-hacking-agent
ExecStart=/opt/ai-hacking-agent/venv/bin/python main.py api-server --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

# 启动服务
sudo systemctl daemon-reload
sudo systemctl start ai-hacking-agent
sudo systemctl enable ai-hacking-agent

# 查看状态
sudo systemctl status ai-hacking-agent
```

## 四、Docker 部署步骤（可选）

### 第1步：安装 Docker
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com | bash
sudo usermod -aG docker $USER
```

### 第2步：构建镜像
```bash
cd /opt/ai-hacking-agent
docker build -t ai-hacking-agent:latest .
```

### 第3步：运行容器
```bash
docker run -d \
  --name ai-hacking-agent \
  -p 8000:8000 \
  -e LLM_API_KEY=你的API密钥 \
  -e LLM_BASE_URL=https://api.deepseek.com/v1 \
  -e LLM_MODEL=deepseek-chat \
  -v $(pwd)/data:/app/data \
  --restart always \
  ai-hacking-agent:latest
```

### 第4步：查看日志
```bash
docker logs -f ai-hacking-agent
```

## 五、配置说明

### .env 文件配置项

| 配置项 | 必填 | 默认值 | 说明 |
|--------|------|--------|------|
| LLM_API_KEY | 是 | 无 | AI API密钥 |
| LLM_BASE_URL | 否 | https://api.deepseek.com/v1 | AI API地址（OpenAI兼容格式） |
| LLM_MODEL | 否 | deepseek-chat | AI模型名称 |
| API_HOST | 否 | 127.0.0.1 | API服务监听地址（0.0.0.0表示所有网卡） |
| API_PORT | 否 | 8000 | API服务端口 |
| DEBUG | 否 | false | 调试模式（true会显示详细错误信息） |
| MAX_WORKERS | 否 | 4 | 最大并发工作数 |
| REQUEST_TIMEOUT | 否 | 300 | 请求超时时间（秒） |

只要兼容 OpenAI API 格式的平台都可以用：

| 平台 | BASE_URL | 推荐模型 |
|------|----------|----------|

## 六、使用方法

### 1. API 文档
启动服务后，浏览器访问 http://127.0.0.1:8000/docs ，可以看到完整的API文档（Swagger UI）。

### 2. 常用 API 接口

#### 健康检查
```
GET /health
```

#### 创建扫描任务
```
POST /api/v1/tasks
Body:
{
  "target": "http://example.com",
  "task_type": "scan",
  "description": "测试扫描"
}
```

#### 获取任务状态
```
GET /api/v1/tasks/{task_id}
```

#### 获取任务结果
```
GET /api/v1/tasks/{task_id}/result
```

#### 生成报告
```
POST /api/v1/reports/generate
Body:
{
  "task_id": "任务ID",
  "format": "html"
}
```

#### CVE 漏洞查询
```
GET /api/v1/knowledge/cve
GET /api/v1/knowledge/cve/{cve_id}
```

#### POC 库查询
```
GET /api/v1/poc/library
GET /api/v1/poc/library/{poc_id}
```

### 3. 命令行使用

```bash
# 初始化
python main.py init

# 启动API服务
python main.py api-server --host 127.0.0.1 --port 8000

# 单次扫描
python main.py scan --target http://example.com

# Nuclei扫描
python main.py nuclei --target http://example.com

# 生成报告
python main.py report --task-id 任务ID --format html
```

## 七、常见问题

### Q1：pip install 报错，找不到版本？
A：
```bash
# 升级pip
python -m pip install --upgrade pip

# 换国内源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q2：启动报错 "No module named xxx"？
A：依赖没装全，重新安装：
```bash
pip install -r requirements.txt
```

### Q3：LLM 连接失败？
A：
1. 检查 `.env` 文件中的 `LLM_API_KEY` 是否正确
2. 检查网络是否能访问 `LLM_BASE_URL`
3. 确认API密钥有余额
4. 尝试换一个AI平台

### Q4：端口被占用？
A：
```bash
# Windows查看占用端口的进程
netstat -ano | findstr :8000
# 杀掉进程（替换PID）
taskkill /PID <进程ID> /F

# 或者换个端口启动
python main.py api-server --host 127.0.0.1 --port 8001
```

### Q5：数据库报错？
A：删除 `data/hacking_agent.db` 文件，重新初始化：
```bash
python main.py init
```

### Q6：Nmap/Nuclei 功能用不了？
A：这两个是可选工具，不装也能跑，只是部分功能受限。
- Nmap安装：https://nmap.org/download.html
- Nuclei安装：`go install github.com/projectdiscovery/nuclei/v2/cmd/nuclei@latest`

### Q7：Windows 下 `.env` 文件创建不了？
A：
1. 打开记事本
2. 写入配置内容
3. 另存为，文件名填 `.env`，保存类型选"所有文件"
4. 保存到项目根目录

### Q8：API 服务启动了，但浏览器访问不了？
A：
1. 确认服务启动成功，看到 `Uvicorn running on http://...`
2. 确认防火墙没有拦截端口
3. 尝试用 `127.0.0.1` 而不是 `localhost`
4. 检查 `.env` 中的 `API_HOST` 是否是 `127.0.0.1`（本地访问）或 `0.0.0.0`（远程访问）
