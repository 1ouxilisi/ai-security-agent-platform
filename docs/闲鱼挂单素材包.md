## 五、图片怎么做

你有3种方式做图片：

### 方式1：用手机备忘录截图（最简单，5分钟）
1. 打开手机备忘录
2. 把上面的文案复制进去
3. 调整字体大小，让文字居中
4. 截图
5. 用手机相册裁剪成正方形
6. 完成

### 方式2：用Canva/稿定设计（好看，10分钟）
1. 打开Canva或稿定设计（免费）
2. 搜"闲鱼主图"模板
3. 选一个简洁的模板
4. 把文案填进去
5. 下载
6. 完成

### 方式3：用PPT做（专业，15分钟）
1. 打开PPT
2. 新建幻灯片，设置成正方形（1:1）
3. 背景用深色（深蓝/深灰）
4. 文字用白色，标题大一点
5. 加个边框或装饰
6. 导出为图片
7. 完成

## 六、闲鱼挂单注意事项

### 标题注意
- 别写"黑客"、"攻击"、"入侵"，会被下架
- 写"安全检查"、"漏洞扫描"、"渗透测试"、"安全评估"
- 标题里加价格，吸引人

### 文案注意
- 一定要写"只接合法授权测试"
- 别写能做什么违法的事
- 别承诺100%发现漏洞
- 写清楚交付物（报告）

### 图片注意
- 主图要清晰，文字大一点
- 别放太技术的截图，客户看不懂
- 放服务内容、价格、交付物
- 颜色用深蓝/深灰，显得专业

### 价格注意
- 9.9元是引流价，别指望赚多少钱
- 真正赚钱的是49元和199元
- 可以设置"9.9元起"，实际根据目标复杂度报价
- 别定价太低，显得不专业

### 沟通注意
- 客户问的时候，先问有没有授权书
- 没有授权书的不接
- 先收钱再干活（平台担保交易）
- 报告交付后，要好评和案例

## 七、闲鱼挂单后的操作

### 每天必做
1. 擦亮宝贝（每天1次，提升排名）
2. 看有没有咨询，及时回复（回复率影响排名）
3. 看有没有人下单，及时处理

### 每周必做
1. 优化标题和文案（根据咨询情况调整）
2. 换主图（测试哪个主图点击率高）
3. 看同行在卖什么，参考他们的价格和文案

### 有咨询时
1. 先问："你有目标网站的合法授权吗？"
2. 没有授权的："不好意思，我只接有合法授权的测试"
3. 有授权的：问清楚目标是什么，需要检测什么
4. 报价：简单网站9.9/49，复杂网站199+
5. 让客户拍下，开始干活
