## 计费方式说明

### 按扫描次数计费 (Pro/Enterprise)

- 每次扫描以"任务"为单位计费，一次扫描一个目标域名/IP/资产计为 1 次。
- 月度配额内不额外收费，超出配额按 2 元/次 计费。
- 扫描任务取消不扣费，仅完成的扫描计入配额。

### 按 API 调用计费

- API 调用以"次"为单位，每次 API 请求 (GET/POST) 计为 1 次调用。
- 月度配额内不额外收费，超出配额按 0.01 元/次 计费。
- 批量接口 (如批量导入资产) 按 0.001 元/资产 计费。

### 按存储用量计费

- 扫描报告、资产数据、日志等占用存储空间。
- Pro 版包含 50GB，超出部分按 0.5 元/GB/月 计费。
- Enterprise 版按需扩容，具体容量协商确定。

### 按席位计费

- Pro 版包含 10 个用户席位，超出按 99 元/人/月 计费。
- Enterprise 版不限席位。

## 常见问题

**Q1: 免费版有什么限制? 够用吗?**

A: 免费版每月 10 次扫描、1 个用户、1GB 存储，适合个人安全爱好者学习和测试。如果需要对企业资产做定期评估，建议升级到 Pro 版。

**Q2: Pro 版的 1000 次扫描/月够用吗?**

A: 取决于资产规模。一次完整的 Web 应用扫描 (约 50 个 URL) 计为 1 次。对于 500 人企业，每月对 20 个 Web 应用做一次扫描约 20 次，加上 API 扫描和基线检查，通常 200-500 次/月足够。大多数中小企业 Pro 版完全够用。

**Q3: 私有化部署和 SaaS 有什么区别?**

A: SaaS 版部署在我们的云端，开箱即用，适合快速验证和中小团队。私有化部署将平台安装在企业自己的服务器上，数据完全不出内网，适合对数据安全有严格要求的金融、政府等行业。私有化部署仅 Enterprise 版支持。

**Q4: 扫描会影响业务吗?**

A: 平台扫描采用低速率模式 (默认 5-20 请求/秒)，对正常业务影响极小。建议在业务低峰期执行完整扫描，或使用"被动扫描"模式仅分析流量不主动发包。专业版和企业版支持自定义扫描速率。

**Q5: 我们需要自己有安全团队吗?**

A: 不需要。平台设计为"AI 安全助手"，即使没有专业安全人员也可以使用。AI 引擎会自动分析结果并用通俗语言解释风险和修复方案。企业版还提供技术支持团队协助解读报告。

**Q6: 支持哪些 LLM 大模型?**

A: 平台兼容所有 OpenAI API 格式的大模型，包括 DeepSeek、通义千问、智谱 AI、月之暗面等。私有化部署时可以接入企业自有的大模型服务。Pro 版和 Enterprise 版可使用平台内置的 LLM 额度。

**Q7: 数据安全如何保障?**

A: SaaS 版采用传输加密 (TLS 1.3) + 存储加密 (AES-256)，所有数据隔离存储。私有化部署数据完全在企业内网，不与任何外部服务器通信。平台不收集任何扫描数据用于训练模型。

**Q8: 可以先试用企业版吗?**

A: 可以。我们提供 14 天企业版免费试用，无需信用卡。联系 sales@securityai-platform.com 开通试用。试用期间可体验全部企业版功能。

**Q9: 价格可以优惠吗?**

A: Pro 版年付优惠 2 个月 (即付 10 个月用 12 个月)。Enterprise 版支持按年签约，签约 3 年可享 8.5 折优惠。教育机构和非营利组织可申请教育优惠 (5 折)。

**Q10: 如何升级版本?**

A: 在控制台「账户设置 → 订阅管理」中可以随时升级。升级时按剩余天数补差价即可。降级在下一个计费周期生效，已支付费用不退。
