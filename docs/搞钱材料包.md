# 搞钱材料包 - AI Hacking Agent

## 一、项目介绍（用于合作/引流）

### 项目简介
AI Hacking Agent 是一个企业级全栈安全测试平台，基于AI多智能体技术，自动完成从侦察、漏洞检测、利用验证到报告生成的全流程渗透测试。

### 核心能力
- **99个CVE漏洞库**：覆盖Web、数据库、中间件、操作系统、网络设备、企业应用
- **68个POC利用脚本**：覆盖RCE、SQL注入、XSS、SSRF、文件上传、未授权访问等
- **7大渗透测试模块**：内网渗透、域渗透、外网渗透、AI安全分析、密码安全、流量分析、后渗透
- **4个专业智能体**：侦察智能体、利用智能体、验证智能体、报告智能体
- **84个API端点**：完整的REST API，支持第三方集成
- **专业报告生成**：美观的HTML报告，包含执行摘要、漏洞详情、修复建议
- **MCP协议支持**：可接入Claude、豆包等AI助手

### 技术栈
- 后端：FastAPI + SQLite + Uvicorn
- AI层：ReAct推理引擎 + RAG检索增强 + 多智能体协作
- 安全工具：Nmap、Nuclei、自定义扫描器、POC库
- 前端：Streamlit + Swagger UI
- 其他：MCP服务器、插件系统、用户认证、告警通知

### 项目统计
- Python文件：50+
- 代码总量：~1.3MB
- 单元测试：88个（100%通过）
- 综合评分：9.5/10
