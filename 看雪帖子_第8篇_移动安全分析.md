# 移动安全自动化：APK安全分析引擎开发实战

## 一、移动安全测试的痛点

移动应用安全测试和Web安全完全不同：
- APK是编译后的二进制，需要反编译
- 测试维度多：代码安全、数据安全、通信安全、权限安全
- 工具碎片化：jadx、apktool、dex2jar、mobSF各管一块
- 人工分析慢：一个中等APK要分析半天

我的目标是做一个**APK自动化分析引擎**：上传APK → 自动反编译 → 多维度扫描 → AI分析 → 输出报告。


## 三、预处理：反编译自动化

```python
class APKPreprocessor:
    def __init__(self, apk_path: str):
        self.apk_path = apk_path
        self.work_dir = tempfile.mkdtemp()
    
    async def process(self) -> APKInfo:
        # 1. 用apktool反编译（获取资源和smali）
        await run_command([
            "apktool", "d", self.apk_path,
            "-o", f"{self.work_dir}/apktool", "-f"
        ])
        
        # 2. 用jadx反编译（获取Java源码）
        await run_command([
            "jadx", self.apk_path,
            "-d", f"{self.work_dir}/jadx", "--no-res"
        ])
        
        # 3. 解析AndroidManifest.xml
        manifest = self.parse_manifest(
            f"{self.work_dir}/apktool/AndroidManifest.xml"
        )
        
        # 4. 提取基本信息
        info = APKInfo(
            package_name=manifest.package,
            version=manifest.version_name,
            min_sdk=manifest.min_sdk,
            target_sdk=manifest.target_sdk,
            permissions=manifest.permissions,
            activities=manifest.activities,
            services=manifest.services,
            receivers=manifest.receivers,
            providers=manifest.providers
        )
        
        return info
```

## 四、静态分析：四大维度

### 4.1 代码安全审计

扫描反编译后的Java代码，查找危险API调用：

```python
DANGEROUS_PATTERNS = [
    # 硬编码密钥
    (r'(?i)(api_key|secret|password)\s*=\s*["\'][^"\']+["\']', "硬编码密钥"),
    # 不安全的加密
    (r'DES|ECB|MD5|SHA1', "弱加密算法"),
    # SQL注入风险
    (r'rawQuery|execSQL\(', "SQL注入风险"),
    # 命令注入
    (r'Runtime\.getRuntime\(\)\.exec', "命令注入风险"),
    # 不安全的WebView
    (r'setJavaScriptEnabled\(true\)', "WebView JS启用"),
    # 不安全的文件存储
    (r'MODE_WORLD_READABLE|MODE_WORLD_WRITEABLE', "不安全文件权限"),
]

def scan_code_security(java_files: list[str]) -> list[CodeIssue]:
    issues = []
    for file in java_files:
        content = read_file(file)
        for pattern, desc in DANGEROUS_PATTERNS:
            for match in re.finditer(pattern, content):
                issues.append(CodeIssue(
                    file=file,
                    line=get_line_number(content, match.start()),
                    description=desc,
                    code_snippet=match.group()
                ))
    return issues
```

### 4.2 权限检查

检查应用申请的权限是否合理：

```python
DANGEROUS_PERMISSIONS = {
    "android.permission.READ_SMS": "读取短信",
    "android.permission.SEND_SMS": "发送短信",
    "android.permission.CALL_PHONE": "拨打电话",
    "android.permission.READ_CONTACTS": "读取通讯录",
    "android.permission.ACCESS_FINE_LOCATION": "精确定位",
    "android.permission.RECORD_AUDIO": "录音",
    "android.permission.CAMERA": "相机",
    "android.permission.READ_EXTERNAL_STORAGE": "读取存储",
}

def check_permissions(permissions: list[str]) -> list[PermissionIssue]:
    issues = []
    for perm in permissions:
        if perm in DANGEROUS_PERMISSIONS:
            issues.append(PermissionIssue(
                permission=perm,
                description=DANGEROUS_PERMISSIONS[perm],
                risk="high" if perm in HIGH_RISK else "medium"
            ))
    return issues
```

### 4.3 组件审计

检查四大组件是否导出且无权限保护：

```python
def audit_components(manifest: Manifest) -> list[ComponentIssue]:
    issues = []
    for comp in manifest.exported_components:
        if not comp.permission:
            issues.append(ComponentIssue(
                component_type=comp.type,
                name=comp.name,
                issue=f"导出的{comp.type}未设置权限保护",
                risk="high"
            ))
    return issues
```

### 4.4 网络配置检查

检查是否允许明文流量、是否忽略证书校验：

```python
def check_network_security(apk_dir: str) -> list[NetworkIssue]:
    issues = []
    
    # 检查network_security_config.xml
    config_path = f"{apk_dir}/res/xml/network_security_config.xml"
    if exists(config_path):
        config = parse_xml(config_path)
        if config.allow_cleartext_traffic:
            issues.append(NetworkIssue(
                issue="允许明文HTTP流量",
                risk="high"
            ))
    
    # 检查代码中是否忽略证书校验
    java_files = glob(f"{apk_dir}/**/*.java")
    for f in java_files:
        content = read_file(f)
        if "checkServerTrusted" in content and "空实现" in analyze(content):
            issues.append(NetworkIssue(
                issue="SSL证书校验被绕过",
                risk="critical"
            ))
    
    return issues
```

## 五、AI风险评级

静态分析会找出很多问题，但不是所有问题都同等危险。AI负责评级：

```python
async def ai_risk_assessment(issues: list[BaseIssue], app_info: APKInfo) -> list[RatedIssue]:
```
