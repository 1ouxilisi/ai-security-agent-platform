🧭 说明与目标

本控制台对应方向4「性能极致优化」：通过延迟加载把非核心模块移出启动路径， 冷启动目标从 ~30s 降到 <10s；通过 LRU+TTL 响应缓存让相同请求直接命中，P95 目标 <50ms； 通过信号量 + 后台队列支持 100 并发不崩；通过 索引建议 / 执行计划 / DB 缓存层优化查询；静态资源走 gzip+brotli+长缓存头。 数据每 5 秒自动刷新一次。所有存储均为内存字典模拟，重启即还原。
